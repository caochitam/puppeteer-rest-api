# Changelog

## [1.0.0] - 2025-10-10

### Added
- Initial release of Puppeteer REST API project.
- Implemented core REST endpoints for browser automation, including:
    - Launching and closing browser instances.
    - Page navigation, clicking, typing, and screenshot capture.
    - Waiting for selectors and evaluating JavaScript functions.
- Added support for handling HTML content and screenshots.
- Included basic error handling and response formatting.
- Provided detailed API documentation for all endpoints.
